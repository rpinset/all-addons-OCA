This module allows marking individual timesheet lines as billable and
generating sales orders directly from them, grouping lines by analytic
account and employee.

It is compatible with *crm_timesheet*

**Table of contents**

.. contents::
   :local:

Usage
=====

#. Go to any timesheets. #. Mark the lines you want to invoice as
**Billable**. #. Go to **Timesheets > Timesheets > Timesheets to bill**.
#. Select the lines and use the action **Create Sales Orders**. #. A
sales order is created per analytic account.
