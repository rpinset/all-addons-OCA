Run a reception's quality control inspections directly from the Barcode
app.

When a reception (incoming picking) generates quality inspections
through
`quality_control_stock_oca <https://github.com/OCA/manufacture>`__ (from
the operation type and product quality triggers), this module surfaces
them as a **Quality** tab inside the reception screen. The operator
answers each check — picking a value for qualitative checks, entering a
measure for quantitative ones — and confirms; when an inspection does
not pass, a photo can be attached to it as evidence.

This is a feature module on top of ``barcode_stock``: it adds the
Quality tab by extending the reception screen, without modifying
``barcode_stock`` itself.

Usage
=====

1. Configure which quality tests apply to which products for receptions:
   on the incoming operation type's quality trigger (created by
   quality_control_stock_oca), add trigger lines on the product, its
   template or its category pointing at the test to run.
2. Operators run inspections from the scanner with the same rights as in
   the back office: they need to be *Quality Control* users. Others see
   the **Quality** tab tell them so.
3. In the Barcode app, open a reception. If it has quality inspections,
   a **Quality** tab appears; answer each check and confirm.
4. Every question needs its answer; a measure left blank is not taken as
   0. When an inspection does not pass, tap *Attach photo evidence* to
   add a photo to it (only images are taken).
5. Answers not confirmed yet are kept while you look at another tab of
   the reception.
6. A confirmed inspection shows its answers read-only. If you confirmed
   it by mistake from the scanner, tap *Back to draft*: it reopens with
   its answers filled in, to correct what was wrong and confirm again.
   This is only offered while no supervisor has decided it — a rejection
   (*Failed*) is theirs — and the reception is still open; an inspection
   confirmed in the back office is not reopened from the scanner.
