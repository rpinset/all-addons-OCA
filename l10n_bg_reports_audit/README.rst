Use Cases / Context
===================

This module supports Bulgarian statutory audit and tax reporting
requirements. It is useful for companies that need standard audit
reports and compliant data exports for the National Revenue Agency.

Configuration
=============

To configure this module, open Accounting, then go to Configuration and
review the Bulgarian localization settings. Ensure the required
accounting modules are installed and configured for the company before
generating audit reports.

Usage
=====

To use this module:

1. Open Accounting and go to Reporting.
2. Select the Bulgarian audit reports menu.
3. Choose a report type and set the reporting period.
