This module extends the base address model to better match Bulgarian
address formatting needs. It adds separate fields for building, floor,
and sector, keeping them aligned with the main street line.

It also keeps company and partner address data in sync, so updates to
structured address fields are reflected consistently across both
records.

Use Cases / Context
===================

This addon is useful when you need structured Bulgarian addresses, such
as for regulated documents or integrations that require separate fields
for building, floor, or sector. It complements ``base_address_extended``
by adding local specifics that are common in Bulgarian addresses.

Usage
=====

To use this module:

1. Open a partner or company and edit the address.
2. Fill in the structured fields (street name/number, building, floor,
   sector).
3. The main street line is updated automatically from the structured
   fields.
