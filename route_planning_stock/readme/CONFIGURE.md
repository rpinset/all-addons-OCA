- Go to `Inventory / Configuration / Settings`.
- Enable `Storage Locations` and save.

## Configuring Route Areas
- Go to `Route Planning / Configuration / Areas`.
- Create or edit a Route Area.
- Set the Warehouse if you have more than one warehouse. Otherwise, the system will use the default warehouse for your company.

Upon saving, the system will automatically:
- Create or update a Transit Location under the warehouse view location.
- Create or update stock rules linking the warehouse stock location, the route area transit location, and the customer location.

## Creating or Editing an Operation Type
- Go to `Inventory / Configuration / Operation Types`.
- Create or edit an operation type.
- Set the `Destination Location` field to the transit location created automatically by the Route Area.
