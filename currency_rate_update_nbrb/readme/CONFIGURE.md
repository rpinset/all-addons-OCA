To configure currency rate updates from NBRB:

1. Go to **Accounting → Configuration → Currency Rate Providers**
2. Click **Create** to create a new provider
3. Select **National Bank of Belarus (NBRB)** as the service
4. Choose which currencies you want to automatically update
5. Configure the update schedule (e.g., daily at 9:00 AM)
6. Save the configuration

The module will automatically fetch exchange rates from NBRB on the scheduled time.

You can also manually trigger an update by clicking the **Update Now** button
on the provider record.
