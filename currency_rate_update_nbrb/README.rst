This module allows automatic download of currency exchange rates from
the **National Bank of the Republic of Belarus (NBRB)** using their
official API.

The module provides daily exchange rates for 26+ currencies including
USD, EUR, RUB, CNY, and others, directly from the central bank's
official source.

Installation
============

This module depends on ``currency_rate_update`` from the OCA/currency
repository.

Make sure you have this module installed before installing
``currency_rate_update_nbrb``.

No additional Python dependencies are required - the module uses only
Python standard library.

Configuration
=============

To configure currency rate updates from NBRB:

1. Go to **Accounting → Configuration → Currency Rate Providers**
2. Click **Create** to create a new provider
3. Select **National Bank of Belarus (NBRB)** as the service
4. Choose which currencies you want to automatically update
5. Configure the update schedule (e.g., daily at 9:00 AM)
6. Save the configuration

The module will automatically fetch exchange rates from NBRB on the
scheduled time.

You can also manually trigger an update by clicking the **Update Now**
button on the provider record.

Usage
=====

After configuration, the module works automatically:

- Exchange rates are updated according to your configured schedule
- You can view update history in the provider's logs
- Manual updates can be triggered anytime
- All rates are official NBRB rates

**Supported currencies:** AUD, BGN, UAH, DKK, USD, EUR, PLN, IRR, ISK,
JPY, CAD, CNY, KWD, MDL, NZD, NOK, RUB, XDR, SGD, KGS, KZT, TRY, GBP,
CZK, SEK, CHF, BYN

**Data source:** https://www.nbrb.by/API/ExRates/Rates
