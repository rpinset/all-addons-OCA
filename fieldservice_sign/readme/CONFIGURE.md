Go to *Field Service \> Configuration \> Settings* and open the **Signatures**
section:

1. Enable **On-site Signature Capture** to surface customer signature capture
   on orders. Optionally enable **Require Signature to Complete**.
2. Enable **Document Signing** to allow launching `sign_oca` requests from
   orders. Optionally enable **Require Document Signed to Complete**.
3. Select the **FSM Order Sign Template** used when requesting a document
   signature. The template model must be `fsm.order`.
