1. Go to *Maquila > Programs* and create a program.
2. Set the biministerial resolution code, the modality and the foreign matrix.
3. Optionally link the CNIME contract (Agreement) and set the resolution and
   benefit dates; the benefit expiry is computed from the resolution date and
   the benefit duration (20 years by default).
4. Register the program products with their INTN certificates.
5. Activate the program. The expiry cron will notify managers when a program,
   contract or INTN certificate is about to expire.
