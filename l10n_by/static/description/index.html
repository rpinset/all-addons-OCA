Belarus - Accounting

This is the base module to manage the accounting chart for Belarus in Odoo.

Features

  • Chart of Accounts for Belarus based on Ministry of Finance Decree №50
  • VAT taxes: 20% (standard), 10% (reduced), 0% (export), and exempt
  • Fiscal positions for domestic sales and export
  • Default accounts configuration
  • Support for BYN (Belarusian Ruble) as the main currency

Особенности

  • План счетов для Республики Беларусь на основе Постановления Минфина №50
  • Налоги НДС: 20% (стандартная), 10% (льготная), 0% (экспорт), освобождение
  • Фискальные позиции для внутренних продаж и экспорта
  • Настройка счетов по умолчанию
  • Поддержка белорусского рубля (BYN) в качестве основной валюты

Configuration

The chart of accounts will be automatically installed when creating a new company with Belarus as the country.

To manually install the chart of accounts:

  1. Go to Invoicing/Accounting → Configuration → Settings
  2. In the Fiscal Localization section, select Belarus - Chart of Accounts
  3. Click Install More Packages or configure the chart template
  4. The module will create all accounts, taxes, and fiscal positions

Настройка

План счетов будет автоматически установлен при создании новой компании со страной Беларусь.

Для ручной установки плана счетов:

  1. Перейдите в Бухгалтерия → Настройки → Настройки
  2. В разделе Фискальная локализация выберите Беларусь - План счетов
  3. Нажмите Установить дополнительные пакеты или настройте шаблон плана счетов
  4. Модуль создаст все счета, налоги и фискальные позиции

Usage

After installation, the chart of accounts will be available for use in all accounting operations.

Available VAT Taxes:

  • VAT 20% - Standard rate for most goods and services
  • VAT 10% - Reduced rate for specific goods (food products, children’s goods, pharmaceuticals)
  • VAT 0% - Zero rate for export operations
  • VAT Exempt - For exempt operations (medical services, education, etc.)

Fiscal Positions:

  • Belarus - Domestic - Automatically applied for Belarus companies with VAT number
  • Belarus - Export - Used for export sales (converts 20%/10% VAT to 0%)

Usage

When creating invoices or bills:

  1. Select the appropriate tax (VAT 20%, 10%, 0%, or Exempt)
  2. For export operations, apply the “Belarus - Export” fiscal position
  3. The system will automatically post to the correct accounts

Использование

После установки план счетов будет доступен для всех бухгалтерских операций.

Доступные налоги НДС:

  • НДС 20% - Стандартная ставка для большинства товаров и услуг
  • НДС 10% - Льготная ставка для отдельных товаров (продукты питания, детские товары, медикаменты)
  • НДС 0% - Нулевая ставка для экспортных операций
  • Освобождение от НДС - Для освобожденных операций (медицинские услуги, образование и т.д.)

Фискальные позиции:

  • Беларусь - Внутренние операции - Автоматически применяется для белорусских компаний с УНП
  • Беларусь - Экспорт - Используется для экспортных продаж (конвертирует НДС 20%/10% в 0%)
