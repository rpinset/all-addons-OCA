1. On a bill of materials, set the maquila program, the INTN certificate and,
   per line, the net quantity, loss percentage and origin type.
2. Manufacturing orders built from that BOM inherit the maquila program.
3. Register waste from production and complete it; a destruction drafts a stock
   scrap for the write-off.
4. Run the **VAN** wizard for a period to compute the national added value. It
   requires at least one completed manufacturing order in the period so the
   origin split of the cost can be determined.
