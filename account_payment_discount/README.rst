This module extends the functionality of account payment base to support
discount and to allow users to automatically create early payment
discount move lines.

.. contents::

Use Cases / Context
===================

This module automatically computes early payment discount on payments

If invoice is partially reconciled with refunds, it will automatically
deduct the refund's early payment discount.

Configuration
=============

Configuration used is the same as Odoo standard, it doesn't add any new
configuration
