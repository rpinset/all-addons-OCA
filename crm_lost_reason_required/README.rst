This module makes the lost reason mandatory when marking a CRM lead or
opportunity as lost.

In standard Odoo the lost reason on the "Mark as Lost" wizard is
optional. With this module installed, users must select a lost reason
before confirming.

**Table of contents**

.. contents::
   :local:

Configuration
=============

No configuration is needed. Install the module and the lost reason
becomes required on the Mark as Lost wizard.

Usage
=====

To use this module, you need to:

1. Open a lead or opportunity.
2. Click **Mark as Lost** (or use the lost action).
3. Select a **Lost Reason** — the field is required.
4. Optionally enter feedback, then confirm.
